Task 3 – Calculator with GUI
Description

Build a graphical calculator application using Python Tkinter. It performs basic arithmetic operations through a simple and user-friendly interface.

Features
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Percentage (%)
Decimal Support
Backspace and Clear Buttons
Error Handling

Technologies Used

Python
Tkinter
Task Workflow
Design the calculator interface.
Implement arithmetic operations.
Handle invalid inputs.
Display results dynamically.
Test application functionality.

How to Run

Install Python 3.
Download or clone this repository.
Open the project folder.
Run the following command:
bash
python calculator.py
